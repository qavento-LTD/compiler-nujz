# 🚀 Nujz Programming Language
**Nujz** هي لغة برمجة تعليمية حديثة تعتمد على مفهوم **البرمجة العاطفية (Emotional Programming)**. تم بناؤها باستخدام لغة ++C لتقديم تجربة برمجية تفاعلية تمزج بين المنطق البرمجي والمشاعر الرقمية.

---

## ✨ المميزات الفريدة (Features)
*   **Emotional Variable Memory:** المتغيرات في Nujz ليست مجرد أوعية بيانات، بل لها "مشاعر". المتغير "يفرح" عند استخدامه بكثرة ويغير سلوكه التفاعلي معك.
*   **Hybrid Execution:** تدعم اللغة وضعين للتشغيل:
    1.  **Interpreter Mode:** تنفيذ ملفات الأكواد ذات الامتداد `.nujz`.
    2.  **REPL Mode:** بيئة تشغيل فورية (Runtime) لكتابة الأكواد وتنفيذها سطر بسطر.
*   **Simple Syntax:** قواعد نحوية بسيطة تعتمد على الكلمات المفتاحية المباشرة مثل `out` للطباعة.

---

## 🛠️ كيف تعمل اللغة (Architecture)
تمر لغة Nujz بثلاث مراحل أساسية لمعالجة الكود:

1.  **Lexical Analysis (Lexer):** تحويل الكود النصي إلى سلسلة من الـ Tokens (كلمات مفتاحية، أرقام، نصوص، معرفات).
2.  **Parsing & Interpretation:** تحليل العلاقات بين الـ Tokens وتنفيذها منطقياً.
3.  **Symbol Table:** ذاكرة ذكية تخزن قيم المتغيرات مع إحصائيات استخدامها لتحديد حالتها "العاطفية".
